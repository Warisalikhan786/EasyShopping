# 🛒 E-Commerce App (Flutter + Firebase)

## 📌 Overview

This is a modern E-Commerce mobile application built using **Flutter** and powered by **Firebase**. The app provides a seamless shopping experience with real-time data handling, secure authentication, and user-friendly UI...

---

## 🚀 Features

* 🛍️ Product Listing
  Browse products with images, prices, and details.

* 🔍 Search & Filtering
  Easily find products using search and category filters.

* 🛒 Cart System
  Add, remove, and manage items in the cart.

* 📦 Order Management
  Place orders and track order history.

* 🔔 Notifications
  Receive real-time updates for orders and offers.

* 👤 User Authentication
  Secure login and signup using Firebase Auth.

* ☁️ Firebase Integration

  * Firestore (Database)
  * Firebase Auth
  * Firebase Cloud Messaging (Notifications)

---

## 🛠️ Tech Stack

* **Frontend:** Flutter
* **Backend:** Firebase
* **Database:** Cloud Firestore
* **Authentication:** Firebase Auth
* **Notifications:** Firebase Cloud Messaging

---

## 🎯 Goal

To build a scalable and user-friendly e-commerce application with clean architecture and smooth performance.
